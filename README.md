# Flipkart Mobile Data Analysis Using Python

## Project Overview

This project focuses on Exploratory Data Analysis (EDA) of mobile phones listed on Flipkart with prices under ₹30,000. The main goal is to analyze mobile phone prices, brands, and specifications to identify useful patterns and insights from the collected data.

I used Python and Selenium for web scraping and Pandas for data cleaning and analysis. Matplotlib and Seaborn were used to create visualizations and understand relationships between different features.

## Objectives

- Collect mobile phone data from Flipkart using web scraping.
- Clean and preprocess the collected dataset.
- Analyze mobile phone prices and brand distribution.
- Explore specifications such as RAM, storage, battery, camera, and processor.
- Visualize patterns and relationships using charts.
- Generate insights to help customers compare mobile phones within their budget.

## Technologies Used

- Python
- Selenium
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Project Workflow

1. Data Collection using Selenium
2. Data Cleaning and Preprocessing
3. Exploratory Data Analysis (EDA)
4. Data Visualization
5. Insights and Conclusion

## Key Analysis

- Mobile phone price distribution
- Brand-wise mobile listing comparison
- RAM and storage analysis
- Price comparison across mobile specifications
- Correlation analysis of suitable numerical features

## Expected Outcome

The project helps understand mobile phone pricing patterns, brand representation, and specification differences within the ₹30,000 budget. It demonstrates practical skills in web scraping, data preprocessing, exploratory data analysis, and data visualization.

## Conclusion

This project provided practical experience in collecting, cleaning, analyzing, and visualizing real-world e-commerce product data using Python. It also helped develop data analysis and problem-solving skills.
